# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 한 파일짜리 도구입니다.

## 쓰는 법
1. `index.html`을 브라우저로 엽니다(GitHub Pages로 올려도 됩니다. 맨 위의 `.nojekyll`이 Jekyll 처리를 끕니다).
2. 엑셀에서 머리글 줄부터 응답 범위를 복사해 입력란에 붙여넣습니다. 붙여넣으면 바로 집계하고, `집계하기` 단추나 Ctrl+Enter로 다시 집계할 수 있습니다.

## 집계 규칙
- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖의 값은 제외입니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보여 줍니다. 유효 응답이 0이면 `-`입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 집계하지 않고 화면에 알립니다.

자세한 판단은 [PLAN.md](PLAN.md)에 있습니다.

## 개인정보
외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다. 붙여넣은 데이터는 브라우저 안에서만 계산하며, 보내거나 저장하지 않습니다. 페이지의 Content-Security-Policy가 외부 요청 자체를 막습니다.

## 시험
계산 로직은 `index.html` 안의 `<script id="tally-core">`에 화면과 따로 있습니다. 시험은 이 블록만 꺼내 DOM 없는 환경에서 실행합니다. Node.js 18 이상이 필요하고 설치할 패키지는 없습니다.

```bash
npm test
```
